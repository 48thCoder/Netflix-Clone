# Netflix Clone
This Netflix Clone is a web development project that replicates the user interface and experience of the popular streaming platform, Netflix. Built using HTML and CSS, and designed with Figma, the project focuses on creating a responsive and visually engaging interface that works seamlessly across different devices.

## 📍Key Objectives :
- Replicate Netflix's User Interface
- Responsive Design
- Mobile-First Approach
- Interactive Elements

## 📍Tech Stack :
- HTML
- CSS
- Figma

## 📍Features :
- Grid and Flexbox Layouts
- Hover Effects & Transitions
- Scalability
